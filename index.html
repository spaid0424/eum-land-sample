토지이음 열람 샘플

주소를 검색하면 PNU를 자동으로 입력하고 토지이음 열람 페이지를 새 창으로 엽니다.

토지이음 POST 전송 파라미터

파라미터 설명 PNU 자리 전송값
pnu 필지고유번호 전체 1~19
selSido 시·도 코드 1~2
selSgg 시·군·구 코드 3~5
selUmd 읍·면·동 코드(전송 시 앞에 0을 붙여 4자리로 구성) 6~8
selRi 리 코드 9~10
landGbn 토지 구분: 1은 일반, 2는 산 11
bobn 본번(앞쪽 0 제거) 12~15
bubn 부번(앞쪽 0 제거) 16~19

전송 URL: https://www.eum.go.kr/web/ar/lu/luLandDet.jsp
요청 방식: POST · 전송 대상: 새 창
고정값: selGbn=umd, isNoScr=script, s_type=1, mode=search, add=land

카카오 주소 검색 결과의 건물관리번호에서 PNU를 자동으로 가져옵니다. PNU를 직접 입력하거나 수정한 뒤 열 수도 있습니다.
